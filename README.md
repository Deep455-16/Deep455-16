## 💡 Featured Projects

### 🛡️ [RiskShield AI](https://github.com/Deep455-16/NovaTrust-Banking-RiskShield-Manager): Banking Fraud & Risk Management Copilot
*Python · Machine Learning · Next.js · Zephyr-7B · Ollama · Docker*

Fuses ML classification, anomaly detection and rule-based scoring into a **real-time transaction risk score**, with an evidence-grounded Zephyr-7B copilot that explains flagged transactions and recommends investigative steps. Ships with a one-click local installer and Docker/Nginx deployment.

### 📚 [Stratum AI](https://github.com/Deep455-16/Stratum-AI): Offline Runbook Assistant
🏆 **Winner, Synergy Hackathon (with HPE), Jul 2026** · [Team repo](https://github.com/AvichalKhanna/hpe-runbook)
*Python · FastAPI · FAISS · BM25 · llama.cpp · Qwen2.5*

A fully offline decision-support assistant: **hybrid retrieval** (BM25 + MiniLM + FAISS), reciprocal rank fusion and cross-encoder re-ranking. **Confidence-gated answers** escalate instead of guessing on weak evidence, with an A* planning component, prompt-injection defence, and a live viewer with streaming citation highlighting for line-level verification.

### ⚡ [HeteroAccel](https://github.com/Deep455-16/HeteroAccel): Adaptive GPU Runtime Accelerator for Local LLMs
*C++ · CMake · llama.cpp · Vulkan · GGUF*

A resource-aware runtime for local LLM inference: hardware detection, execution planning, adaptive scheduling, memory management and profiling. Includes **HydroXL**, a native C++ engine (GGUF parser, tokenizer, KV cache, transformer forward pass) with a Vulkan compute path.

| Benchmark | Result |
|---|---|
| Vulkan vs CPU throughput | **5.20 vs 2.07 tok/s** |
| CPU time-to-first-token | **~3.9 s → ~1.9 s** |

*Qwen2.5-0.5B Q4_K_M · Intel Iris Xe · single run*

### 🛰️ [SatQuery AI](https://github.com/Deep455-16/SatQuery-AI-VLA): Agentic Vision-Language Assistant for Remote Sensing
*Python · Rasterio · Flask · React · Gemini 2.5 Flash*

Built for **ISRO/SAC Problem Statement 26167 (Smart India Hackathon)**. A controller routes natural-language queries to specialist tools for VQA, bi-temporal change detection and optical–SAR fusion, with GeoTIFF input validation (dimension/CRS checks), **confidence-scored answers**, visual evidence and an auditable execution trace.

### 🔍 [SafeHire AI](https://github.com/Deep455-16/SafeHire-AI): Offline Document Verification
*Python · FastAPI · OpenCV · Tesseract OCR · scikit-learn*

Flags tampered or AI-generated resumes and certificates using OCR, **Error Level Analysis**, TF-IDF semantic matching and stylometric authorship detection, producing an **explainable Semantic Validity Score**.
