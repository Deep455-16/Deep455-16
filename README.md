## 🚀 About Me

I'm a Computer Science undergrad at Manipal University Jaipur, focused on building AI systems that work **without depending on the cloud** — offline speech-to-text, local RAG pipelines, and self-hosted LLM inference. I like taking projects from a rough hackathon prototype to a production-grade architecture quickly.

Currently building a **RAG-based incident runbook copilot** for HPE, using FAISS + BM25 hybrid search, cross-encoder reranking, and a Qwen2.5 model served locally through Ollama.

## 💡 Featured Project

### Online Meet Expression Analyzer
*Python · OpenCV · YOLO · React.js · FER-2013 · AffectNet*

A facial expression detection system for online meetings that identifies faces across multiple participants and classifies seven expressions to gauge concentration levels.

- Built with MTCNN and Haar Cascade for multi-face detection
- Backend powered by Python, NumPy, and OpenCV
- Frontend built with React.js and HTML/CSS
- Trained on the FER-2013 and AffectNet datasets from Kaggle
